## Consequences
- The only unknown left in the format is the 4-entry codebook (which 2-bit
  code means -1, 0, +1, and what the 4th is). Everything else — block size,
  group size, scale dtype/position, count, element layout — is measured.
- Implementable in q36 as: one gguf_types entry (block_elems 128, block_bytes
  34), one row-dequant, one GEMV kernel. No LUT/grid machinery, unlike the
  i-quants q36 already carries.
- Off-spec type id 142 and the load-time inverse-Hadamard remain the two
  loader-side blockers; the arch (qwen35 hybrid SSM) matches a profile q36
  already declares (q36.c:136/151-154: dt_rank 48, inner 6144, conv 4,
  state 128). See ternary-bonsai-probe.txt.
